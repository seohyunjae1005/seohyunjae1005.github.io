# 반도체 산업 동향·취업 준비 도구

반도체 주요 기업의 공식 발표를 수집해 기술·직무 흐름을 확인하고, 사용자가 입력한 채용공고와 경험을 근거 중심으로 정리하는 개인 프로젝트입니다.

- 공개 사이트: <https://seohyunjae1005.github.io/>
- 핵심 원칙: 원문 사실과 자동 해석 분리, 근거 없는 내용 생성 금지, 개인정보의 브라우저 내부 저장

## 주요 기능

### 산업 동향

- 삼성전자, SK하이닉스, Micron, Kioxia, TSMC, Intel과 주요 반도체 장비사의 공식 뉴스 수집
- 최근 7·30·90일 기술, 직무, 기업 발표 흐름 집계
- 기사 원문 링크, 한국어 요약, 기술 분야와 관련 직무 제공
- 원문에서 확인한 사실과 AI 영향 가설을 분리한 기사 분석
- 새 기사가 있을 때만 발송하는 일간·주간 이메일 리포트

### 취업 준비

- 채용공고 원문을 의미 단위로 나누고 Fact와 자동 해석을 분리한 JD 분석
- 모든 주요 판단에 JD 원문 근거 연결
- 프로필 경험을 관찰·직접 수행·진행 중·예정 수준으로 구분해 과장 방지
- JD 요구사항과 저장한 경험의 직접·간접·근거 없음 연결
- 자기소개서 문항별 경험 배치, 작성 개요, 초안 근거 검토
- 문항 간 반복 표현, 경험 원문에서 확인되지 않은 수치, 글자 수 제한 점검
- 검토본과 제출용 답변 분리 내보내기
- 회사·직무·JD별 지원 작업 최대 8건 로컬 저장

## 신뢰도와 개인정보 원칙

- JD에 없는 Tool, 성과지표, 경험은 요구사항처럼 표시하지 않습니다.
- 자동 해석에는 근거가 된 JD 문장을 연결합니다.
- 합격 가능성이나 다른 지원자와의 우열을 예측하지 않습니다.
- 프로필, JD, 자기소개서 초안은 사용자의 브라우저 저장 공간에만 보관합니다.
- AI 검토 버튼을 누른 경우에만 필요한 텍스트가 연결된 Apps Script 분석 서버로 전송됩니다.
- 공개 저장소와 사이트 코드에는 API 키와 구독자 이메일을 저장하지 않습니다.

## 프로젝트 구조

- `config/sources.yaml`: 공식 수집 채널 설정
- `src/trend_tracker/`: 기업별 수집·분류·동향 집계 로직
- `scripts/`: 일일 수집, 번역, 분석, 이메일 생성 작업
- `docs/`: GitHub Pages 사이트와 공개 데이터
- `google_apps_script/`: 구독 메일 및 JD 분석 API 코드
- `tests/`: 수집·분류·JD·프로필·지원서 기능 자동검사

## 로컬 검사

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
$env:PYTHONPATH='.;src'
python -m unittest discover -s tests -p 'test_*.py'
node tests/test_application_workspace.js
node tests/test_jd_ai_client.js
node tests/test_jd_api_pipeline.js
```

## 자동 실행

GitHub Actions가 공식 기사 수집, 데이터 검사, 공개 페이지 갱신과 이메일 미리보기 생성을 수행합니다. 개별 회사의 접근 오류가 전체 수집을 중단시키지 않도록 이전 정상 데이터와 품질검사를 함께 사용합니다.

## 한계

- 기사 수는 공식 발표 빈도이며 시장점유율이나 투자 중요도를 의미하지 않습니다.
- JD 분석은 입력한 공고 원문 범위 안에서만 판단합니다.
- 자동 점검 통과는 채용 조건 충족이나 합격을 의미하지 않습니다.
- 최종 지원 전 기업 채용 페이지의 최신 공고, 문항과 글자 수 제한을 직접 확인해야 합니다.
