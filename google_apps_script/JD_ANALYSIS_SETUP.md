# JD AI 분석 연결 설정

현재 GitHub Pages는 정적 사이트이므로 Gemini API 키를 직접 넣으면 안 됩니다. `JdAnalysisApi.gs`를 별도의 Google Apps Script 웹 앱으로 배포해 키를 숨깁니다.

1. Google Apps Script에서 새 프로젝트를 만듭니다.
2. 기본 코드를 모두 지우고 `JdAnalysisApi.gs` 전체를 붙여 넣어 저장합니다.
3. **프로젝트 설정 → 스크립트 속성**에 아래 값을 추가합니다.
   - 속성: `GEMINI_API_KEY`
   - 값: Gemini API 키
   - 선택 속성: `GEMINI_MODEL` / 기본값 `gemini-3.5-flash-lite`
4. **배포 → 새 배포 → 웹 앱**을 선택합니다.
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
5. 생성된 `/exec` 주소를 사이트의 **AI 분석 연결 설정**에 한 번 저장합니다.

이 주소는 현재 브라우저의 `localStorage`에만 저장됩니다. 사이트 저장소에는 Gemini 키나 배포 주소를 기록하지 않습니다.

## 안전장치

- 한 번에 최대 30,000자만 받습니다.
- 스크립트 캐시 기준 하루 100회로 제한합니다.
- AI가 제시한 모든 근거 인용이 JD 원문에 실제 존재하는지 확인합니다.
- 근거 인용을 찾지 못한 Fact와 해석은 화면에 보내기 전에 제외합니다.
- 사용자 프로필과 경험은 이번 API에 보내지 않습니다.
