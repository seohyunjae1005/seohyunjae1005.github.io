# 12주차 외부 사용자 테스트 안내

## 목적

처음 방문한 사용자가 별도 설명 없이 산업 동향과 취업 준비 기능의 핵심 흐름을 찾고, 원문 사실과 자동 해석을 구분할 수 있는지 확인한다.

## 진행 방법

1. 테스트 참가자에게 사이트 하단의 `3분 사용성 테스트 참여하기` 링크를 전달한다.
2. 참가자는 A·B·C 중 하나를 선택하고 `산업 동향·뉴스` 또는 `JD·취업 준비` 중 하나의 기능 5개를 직접 수행한다.
3. 참가자가 만든 결과 문장을 전달받아 아래 표에 기록한다.
4. 3명 중 2명 이상이 실패하거나 평균 점수가 3점 미만인 항목을 우선 개선한다.

개인정보는 받지 않으며, 결과에는 테스터 구분 문자와 기능 평가만 기록한다.
